# Dziennik nauki

Po każdym tickecie 3–4 zdania: czego się nauczyłem, co było trudne, czego jeszcze nie rozumiem.
Na retro Claude robi z tego krótki quiz i wraca do punktów „nie rozumiem”.

Format wpisu:

```markdown
## RRRR-MM-DD · REV-x — <tytuł ticketu>
- **Nauczyłem się:** ...
- **Trudne:** ...
- **Nie rozumiem jeszcze:** ...
```
